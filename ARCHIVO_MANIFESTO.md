# Manifiesto del archivo Aurea3D Premium

## Alcance

Este archivo reúne el material generado y validado durante la sesión: código fuente del proyecto, configuración, esquema y migraciones Drizzle, tests Vitest, documentación técnica, informe de auditoría, guía operativa en portugués, notas de verificación, resumen de versiones, registro conversacional disponible y archivos de seguimiento.

## Historial

La trazabilidad de versiones se conserva en Git mediante los commits `f07aee7`, `2d55a98`, `1948116`, `db9fa67` y `f7b8516`. La versión funcional recomendada es `db9fa67`; el commit de archivo añade los documentos de auditoría y archivo.

## Assets

Los assets SVG persistentes utilizados por el Portfolio se referencian desde almacenamiento compatible con el despliegue. El código conserva las URLs persistentes y el archivo incluye la documentación de su uso. No se incluyen `node_modules`, `dist`, logs internos del sandbox, secretos, archivos `.env` ni credenciales.

## Conversación

`CHAT_DISPONIBLE.md` contiene el resumen fiel del historial recuperable. No se presenta como una transcripción literal completa, porque el export íntegro del chat no está disponible para lectura directa tras la compactación de contexto.

## Destinos previstos

El paquete se subirá a un repositorio GitHub nuevo y privado y a una carpeta privada de Google Drive. La visibilidad no se cambiará a pública y no se compartirán enlaces con terceros.
